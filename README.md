# OSCAR-FE-model
Open-source physics-based FeFET Verilog-A model for SPICE simulation.

## Description

OSCAR-FE is a SPICE-compatible ferroelectric FET (FeFET) model
based on multi-domain NLS switching dynamics including:

- Polycrystalline domain distribution
- Temperature effects
- Device variation
- Poole-Frenkel leakage
- 2000-domain stochastic switching

## Files

- nls_hysteresis.va → FeCAP Verilog-A model

## Requirements

- Cadence Spectre
- SPICE simulator supporting Verilog-A
